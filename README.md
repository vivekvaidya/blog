## Technical Details

This blog is built with [Jekyll](https://jekyllrb.com/) and hosted on [GitHub Pages](https://pages.github.com/). It uses a modified version of the [Poole](https://github.com/poole/poole) theme.

To run locally:
```bash
bundle install
bundle exec jekyll serve
```

To deploy, simply push to the `master` branch. GitHub Pages will automatically build and deploy the site.
